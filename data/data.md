# Dataset Reference

## Overview

The original dataset used in this project was privately provided and is not publicly available for redistribution due to data privacy and access restrictions.

Therefore, the original dataset files are not included in this repository.

For reference, a publicly available dataset with a similar structure and prediction objective is provided below. It offers a close representation of the original dataset, with an estimated similarity of over 90% in terms of its overall structure and characteristics.

## Reference Dataset

**[NYC Taxi Trip Duration – Kaggle](https://www.kaggle.com/datasets/yasserh/nyc-taxi-trip-duration)**

This dataset contains New York City taxi trip records, including information such as:

- Pickup and drop-off timestamps.
- Pickup and drop-off geographical coordinates.
- Passenger count.
- Vendor information.
- Trip duration (target variable).

## Download Instructions

1. Visit the Kaggle dataset page using the link above.
2. Sign in to your Kaggle account.
3. Click the **Download** button.
4. Extract the downloaded files.
5. Place the required dataset files inside this directory if you want to explore the reference data.

## Important Notes

- The Kaggle dataset is provided for reference purposes only.
- It is not the actual dataset used in this project.
- The original dataset was privately accessed and cannot be shared publicly.
- The estimated similarity of over 90% refers to the overall data structure and characteristics, not an officially verified equivalence.
- The reference dataset is not guaranteed to reproduce the exact results of this project.
